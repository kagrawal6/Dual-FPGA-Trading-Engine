% ---- MOTIVATION --------------------------------------------------------
\sectionbox{uwred}{Motivation}{%
Modern electronic trading demands \textbf{deterministic,
sub-microsecond decision-making}. General-purpose CPUs introduce
unpredictable jitter from OS scheduling, cache misses, and interrupts
(typically 10--100\,$\mu$s), making software-based latency measurement
unreliable and trading non-deterministic.

\vspace{0.20in}
Our project demonstrates that an \textbf{FPGA fabric} can guarantee a
\textbf{fixed, predictable pipeline latency with zero jitter} for every
market event --- and that \textbf{all performance metrics can be
measured in hardware}, free from OS contamination.

\vspace{0.22in}
\textbf{Why two physically separate FPGAs?}

\vspace{0.10in}
A single FPGA looping back to itself would be trivially simple and
unrealistic. Two boards force real engineering challenges:

\vspace{0.12in}
\begin{itemize}[leftmargin=0.35in, itemsep=0.08in, labelsep=0.12in]
  \item[\color{uwred}\faIcon{microchip}]
    Custom \textbf{physical-layer link} design across a cable
  \item[\color{uwred}\faIcon{sync}]
    \textbf{Clock domain crossing} between independent oscillators
  \item[\color{uwred}\faIcon{project-diagram}]
    Clean \textbf{separation of concerns}: Exchange vs.\ Trader
    mirrors real-world infrastructure
  \item[\color{uwred}\faIcon{chart-line}]
    \textbf{Hardware-measured} latency, throughput, and P\&L ---
    not software estimates
\end{itemize}%
}

\vspace{0.50in}

% ---- BOARD A -----------------------------------------------------------
\sectionbox{boardAcolor}{Board A \;\textemdash\; Exchange-Lite}{%
Simulates a simplified stock exchange with a synthetic market model
for \textbf{16 real S\&P\,500 tickers} across 8 GICS sectors:

\vspace{0.12in}
\begin{itemize}[leftmargin=0.35in, itemsep=0.08in, labelsep=0.12in]
  \item[\color{boardAcolor}\faIcon{chart-bar}]
    \textbf{Market Simulator:} LFSR-based noise engine generates
    realistic bid/ask quotes with correlated sector drift
  \item[\color{boardAcolor}\faIcon{bolt}]
    \textbf{4 Market Regimes:} CALM, VOLATILE, BURST, ADVERSARIAL
    --- switchable at runtime via PS or physical buttons
  \item[\color{boardAcolor}\faIcon{exchange-alt}]
    \textbf{Order Matching:} Matches incoming orders against current
    best prices; returns FILL or REJECT within \textbf{1 cycle}
  \item[\color{boardAcolor}\faIcon{filter}]
    \textbf{TX Arbiter:} Prioritizes fills/rejects over the quote
    stream for fair bandwidth allocation on the link
  \item[\color{boardAcolor}\faIcon{cog}]
    \textbf{AXI-Lite Control:} Per-symbol init prices, spreads,
    and sector IDs configurable from Python over MMIO
\end{itemize}

\vspace{0.15in}
\textbf{FSM:}\; RESET $\to$ IDLE $\to$ RUNNING $\leftrightarrow$ STOPPED\\[0.06in]
\textbf{Verified on silicon}: all 16 symbol slots exercised from
PYNQ Jupyter over AXI-Lite MMIO at 50\,MHz PL clock.%
}

\vspace{0.50in}

% ---- LINK LAYER --------------------------------------------------------
\sectionbox{linkcolor}{Board-to-Board Link Layer}{%
Full-duplex communication over PMOD cables with
custom serialization and CDC:

\vspace{0.12in}
\begin{itemize}[leftmargin=0.35in, itemsep=0.08in, labelsep=0.12in]
  \item[\color{linkcolor}\faIcon{plug}]
    \textbf{Physical:} 2$\times$ PMOD cables (JA: A$\to$B, JB: B$\to$A)
    for simultaneous quote delivery and order return
  \item[\color{linkcolor}\faIcon{clock}]
    \textbf{Mesochronous Clocking:} Each board runs its own oscillator;
    a 2-FF CDC synchronizer at the RX side handles clock differences
  \item[\color{linkcolor}\faIcon{database}]
    \textbf{128-bit Frames:} Fixed-format messages (QUOTE, ORDER, FILL)
    serialized as 32 nibbles over a 4-bit data path
  \item[\color{linkcolor}\faIcon{tachometer-alt}]
    \textbf{Throughput:} $\sim$1.47\,M frames/s sustained at 50\,MHz
    nibble rate; 640\,ns serialization per frame
  \item[\color{linkcolor}\faIcon{handshake}]
    \textbf{Backpressure:} Ready/valid handshake prevents data
    loss under burst conditions; 40\,ns minimum inter-frame gap
\end{itemize}

\vspace{0.12in}
All prices encoded in \textbf{Q16.16 fixed-point} (16-bit integer,
16-bit fraction) for cycle-efficient arithmetic without floating-point
units.%
}

% ---- BOARD B -----------------------------------------------------------
\sectionbox{boardBcolor}{Board B \;\textemdash\; Trader Pipeline}{%
Processes every quote through an \textbf{8-stage deterministic
pipeline} with guaranteed fixed latency:

\vspace{0.12in}
\begin{itemize}[leftmargin=0.35in, itemsep=0.08in, labelsep=0.12in]
  \item[\color{boardBcolor}\faIcon{inbox}]
    \textbf{Msg Demux:} Separates incoming QUOTEs from FILLs
    based on frame type field
  \item[\color{boardBcolor}\faIcon{book}]
    \textbf{Quote Book:} Maintains best bid/ask for all 16 symbols
  \item[\color{boardBcolor}\faIcon{square-root-alt}]
    \textbf{Feature Compute:} Exponential Moving Average (EMA) with
    configurable $\alpha$; computes price deviation from fair value
  \item[\color{boardBcolor}\faIcon{brain}]
    \textbf{Strategy Engine:} Mean-reversion baseline --- buys when
    price deviates below EMA by threshold, sells when above
  \item[\color{boardBcolor}\faIcon{shield-alt}]
    \textbf{Risk Manager:} Enforces per-symbol position limits and
    tracks pending orders to prevent over-exposure
  \item[\color{boardBcolor}\faIcon{paper-plane}]
    \textbf{Order Manager:} Formats and serializes orders for
    transmission back to Board A
  \item[\color{boardBcolor}\faIcon{wallet}]
    \textbf{Position Tracker:} Real-time P\&L, cash accounting,
    and fill reconciliation
  \item[\color{boardBcolor}\faIcon{stopwatch}]
    \textbf{Latency Histogram:} Cycle-accurate round-trip
    measurement computed entirely in FPGA fabric (16 bins)
\end{itemize}

\vspace{0.15in}
\textbf{FSM:}\; RESET $\to$ IDLE $\to$ ARMED $\to$ TRADING
$\leftrightarrow$ HALTED%
